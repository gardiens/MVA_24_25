# TP Diffusion models

## Requirements

See requirements.txt for the list of required packages. You can install them with the following command:

```
conda install diffusers accelerate torch matplotlib
```


## Kernel database

The kernel database "custom_blur.mat" used in the dataloader can be downloaded at the following adress:
```
https://drive.google.com/file/d/1fDtSwItCCqob6ZJ_zvVfvQJ8U1q7dV7D/view?usp=share_link
```
